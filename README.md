# karthikankam.github.io

Personal portfolio website for Karthik Ankam — AI & Data Science enthusiast.

🔗 **Live:** [karthikankam.github.io](https://karthikankam.github.io)

## Features
- Dark theme with neon-green accent
- Scroll-reveal animations
- Responsive design (mobile-friendly)
- Sections: Hero, About, Skills, Projects, Experience, Contact
- All project links connected to GitHub repos

## Tech Stack
- Pure HTML, CSS, JavaScript
- Google Fonts (Instrument Serif, DM Sans, JetBrains Mono)
- IntersectionObserver for scroll animations
- CSS custom properties for theming
